# Prismatic raytracer

Sources: résumé and public repository README at
https://github.com/AdilRMallick/prismatic-raytracer.

## Rendering implementation

- Built a recursive raytracer in C++ using object-oriented design and a provided OpenGL/MFC framework.
- Implemented configurable recursion depth, Phong ambient, diffuse, and specular shading, hard shadows, textures, recursive reflection, and refraction.
- Added an OpenGL preview for inspecting the scene before rendering.
