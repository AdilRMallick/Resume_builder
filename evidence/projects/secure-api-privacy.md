# Secure API privacy dashboard

Source: public repository README at
https://github.com/AdilRMallick/secure-api-privacy.

## Privacy review workflow

- Built a React 18 and Node.js/Express application for cataloging API endpoints and assessing privacy risk across six dimensions.
- Added automated findings, remediation tracking, review workflows, charts, reports, and CSV export.

## Authentication and authorization

- Used MongoDB with Mongoose for persistence, JSON Web Tokens for sessions, and bcrypt for password hashing.
- Implemented role-based access for administrator, reviewer, and viewer roles across backend routes and frontend pages.
